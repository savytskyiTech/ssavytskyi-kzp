# ssavytskyi-kzp

Лабораторні роботи з дисципліни «Кросплатформні засоби програмування».

- Варіант: **21** («Ветклініка»).
- ШІ-асистент: **Claude Code** (до 2026-11-01 — OpenAI Codex).
- Ціль: рівень 2, після його перевірки — рівень 3.

## Організація роботи

Один репозиторій для всього курсу. `main` захищена і містить перевірені результати;
зміни надходять через Pull Request. Java-інфраструктура й поточна робота ведуться в гілці
`java/infra` (модель «один репозиторій + мовні гілки» з `MAVEN_ACTIONS_GUIDE`).

Кожна лабораторна лежить у власній теці `LAB_01/`, `LAB_02/`, … з окремими `pom.xml`,
`README.md` і `REPORT.md`, тож після злиття до `main` попередні роботи лишаються доступними.

| Робота | Тема | Тека | Стан |
| --- | --- | --- | --- |
| № 1 | Ветклініка: розгортання Java-проєкту та базова обробка даних | [`LAB_01/`](LAB_01/) | Злито в `main` (PR #9) |
| № 2 | Ветклініка: класи, record та інкапсуляція | [`LAB_02/`](LAB_02/) | Реалізовано; очікує PR і CI |
| № 3 | Ветклініка: спадкування, enum і поліморфізм | [`LAB_03/`](LAB_03/) | Реалізовано; очікує PR і CI |

## Початок роботи

1. Перевірити інструменти за [docs/SETUP.md](docs/SETUP.md) (потрібна JDK 21).
2. Перейти в теку роботи й виконати команди з її `README.md`, наприклад `cd LAB_01 && ./mvnw verify`.
3. Працювати невеликими кроками за [GitHub Issues](https://github.com/savytskyiTech/ssavytskyi-kzp/issues);
   шаблони Issues і PR — у `.github/` (з Додатка А методички `LAB_01`).

Перевірки на трьох ОС: [Lab 01 CI](https://github.com/savytskyiTech/ssavytskyi-kzp/actions/workflows/lab01-ci.yml),
[Lab 02 CI](https://github.com/savytskyiTech/ssavytskyi-kzp/actions/workflows/lab02-ci.yml),
[Lab 03 CI](https://github.com/savytskyiTech/ssavytskyi-kzp/actions/workflows/lab03-ci.yml).

## ШІ-агенти

Правила для агентів — у [`AGENTS.md`](AGENTS.md) (Claude Code підключає їх через `CLAUDE.md`),
ролі Менеджер, DevOps, Розробник, Валідатор, Документатор і Рецензент — у `.claude/agents/`.
Використання ШІ описується в розділі «Академічна доброчесність» звіту кожної роботи.
