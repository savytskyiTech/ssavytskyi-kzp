# Звіт до лабораторної роботи № 1

**Чернетка.** Опубліковано структуру, стартовий CLI та інфраструктуру CI.
Предметна обробка CSV й здача ще не виконані. Незавершені розділи
заповнюються фактичними результатами.

## 1. Тема, номер і варіант

Розгортання Java-проєкту та базова обробка даних. Лабораторна № 1,
варіант 21 — «Ветклініка». Середовище підготовки: macOS, ARM64.
ПІБ і академічну групу студент додасть перед здачею.

## 2. Мета роботи

Навчитися створювати відтворюваний Java-проєкт, перевіряти вхідні дані,
обчислювати показники та перевіряти роботу на різних ОС.
Досягнуто: опрацьовано вимоги та підготовлено структуру репозиторію.

## 3. Постановка задачі

Формат: `animal;species;visitType;price;urgent`.
Показники: кількість коректних записів, середня вартість, загальний виторг,
кількість ургентних візитів. Уточнення валідації описано в README.

## 4. Структура програми

Стартовий клас `ua.lpnu.kzp.Main` підтримує довідку та версію з ресурсу
`version.properties`, сформованого Maven. Без аргументів він явно повідомляє,
що обробку CSV ще не реалізовано. `MainTest` запускає CLI в окремій JVM
і перевіряє звичайний запуск, довідку, версію та невідомий аргумент.
Потік предметних даних буде описано після реалізації обробки CSV.

## 5. Інфраструктура

Підготовлено Git, `.gitignore`, `.gitattributes`, `.editorconfig`, `AGENTS.md`
та описи ролей у `ai/`. Перевірений стан інструментів — у `../docs/SETUP.md`.
Додано Maven POM: Java 21, UTF-8, JUnit 5.12.2, Surefire 3.5.3,
SpotBugs 4.9.7.0 у фазі `verify`, Shade 3.6.0 для виконуваного `*-all.jar`.
Maven Wrapper використовує офіційні scripts Apache 3.3.4 та Maven 3.9.11
із перевіркою SHA-256 дистрибутива. Scripts розпаковано з офіційного
`maven-wrapper-distribution-3.3.4-only-script.zip`; локальний Maven plugin
генерації не виконувався через відсутність JDK.
Workflow запускає `clean verify`, перевіряє JAR та зберігає артефакти
на Ubuntu, Windows і macOS. У ресурс версії передається номер запуску CI.

## 8. Тестування

- `git --version`: `2.54.0 (Apple Git-157)`.
- `java -version`: Java Runtime не знайдено.
- Локальна JDK ще недоступна: завантаження архіву обривалося, локальні
  Java-збірка та тести не виконувалися.
- Workflow перевірено через `actionlint 1.7.12`, scripts через `bash -n`;
  XML POM і `git diff --check` пройшли перевірку.
- Запущено [Lab 01 CI](https://github.com/savytskyiTech/ssavytskyi-kzp/actions/runs/40777272702).
  Коміт `a76741c`, запуск № 1, усі три jobs завершилися успішно.
- Структуру, UTF-8/LF та розраховані очікування прикладу CSV перевірено;

## 10. Академічна доброчесність

Використано **OpenAI Codex**. У цьому етапі асистент виконував ролі
Менеджера й DevOps у поточному чаті; окремі агенти не запускалися.

Запит студента: розпочати лабораторні для варіанта 21 на рівень 2 або 3,
використовувати Codex замість Copilot, один репозиторій `ssavytskyi-kzp`
з окремими гілками лабораторних.

Внесок Codex: опрацювання чотирьох наданих PDF, виділення вимог варіанта,
підготовка структури, правил, ролей, плану, синтетичного прикладу даних
та цієї чернетки звіту; перевірка локального середовища, створення
репозиторію після підтвердження Public, завантаження гілок і створення Issues.
На запит «спочатку actions для перевірки на трьох ос» Codex додав POM,
офіційні scripts Wrapper, workflow, стартовий CLI та чотири тести
інфраструктури. Асистент перевірив workflow через actionlint і запустив CI.
Предметний Java-код обробки ветклініки на цьому етапі не створювався.

Рішення про рівень 2 як перший етап та рівень 3 як наступний запропонував Codex.
Студент перевірить підготовлені матеріали й запише прийняті рекомендації,
власні зміни та пояснення реалізації. Підтвердження розуміння коду
буде додано студентом після реалізації та перевірки.

Виправлених дефектів програми поки немає: програма ще не написана.
