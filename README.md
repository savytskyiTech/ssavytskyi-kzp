# ssavytskyi-kzp

Лабораторні роботи з дисципліни «Кросплатформенні засоби програмування».

- Варіант: **21**.
- ШІ-асистент: **OpenAI Codex**.
- Початкова ціль: рівень 2; після його перевірки можна додати вимоги рівня 3.
- Статус: Maven і CI лабораторної № 1 додано; предметна логіка ще не реалізована.

## Організація роботи

Один репозиторій для всього курсу. `main` містить перевірені результати.
Кожна лабораторна виконується в окремій гілці `codex/lab-NN`, а після
перевірки додається до `main` через Pull Request. Наступна гілка створюється
від оновленої `main`. Гілки попередніх лабораторних зберігаємо.

Каталоги `LAB_01/`, `LAB_02/` тощо зберігають окремі роботи та їхні звіти,
щоб після злиття до `main` попередні результати залишалися доступними.
Це організаційне рішення для обраного студентом формату одного репозиторію.

| Робота | Тема | Гілка | Стан |
| --- | --- | --- | --- |
| № 1 | Ветклініка: розгортання Java-проєкту та базова обробка даних | `codex/lab-01` | Перевірка інфраструктури CI |

## Початок роботи

1. Виконати перевірки з [docs/SETUP.md](docs/SETUP.md).
2. У гілці `codex/lab-01` працювати з каталогом `LAB_01/`.
3. Виконати команди з `LAB_01/README.md`, потім реалізовувати предметну
   програму невеликими кроками за GitHub Issues.

Перевірки на трьох ОС: [Lab 01 CI](https://github.com/savytskyiTech/ssavytskyi-kzp/actions/workflows/lab01-ci.yml).

Правила для Codex містяться в `AGENTS.md`, описи ролей — у `ai/`.
Кожна лабораторна має власні `README.md` і `REPORT.md`.
