# Лабораторна робота № 1 — Ветклініка

**Варіант 21.** Розгортання Java-проєкту та базова обробка даних.
Поточний етап: постановка задачі та підготовка структури. Програми й Maven
Wrapper ще немає, наведені нижче вимоги є планом реалізації.

## Задача

Прочитати візити до ветклініки з UTF-8-файла, перевірити записи,
обчислити показники та сформувати однаковий звіт у консолі й файлі.

Формат одного рядка, без заголовка:

```text
animal;species;visitType;price;urgent
```

| Поле | Тип | Перевірка |
| --- | --- | --- |
| `animal` | `String` | Непорожнє ім'я тварини |
| `species` | `String` | Непорожній вид тварини |
| `visitType` | `String` | Непорожній тип візиту |
| `price` | `double` | Скінченне невід'ємне число, десяткова крапка |
| `urgent` | `boolean` | Рівно `true` або `false` |

У рядку має бути рівно п'ять полів. Крайові пробіли полів прибираємо.
Довідники видів і типів візиту методичкою не задані; непорожній текст допустимий.
Нульова ціна допустима. Вимога скінченності виключає `NaN` та нескінченність.
Це уточнення валідації для реалізації, а не додаткові поля варіанта.

Показники для коректних записів:

1. Кількість записів.
2. Середня вартість візиту.
3. Загальний виторг — сума вартостей візитів.
4. Кількість ургентних візитів (`urgent=true`).

За відсутності коректних записів лічильники й виторг дорівнюють нулю,
а замість середнього виводиться «немає даних».
Це обрана поведінка порожньої вибірки, яку потрібно перевірити тестом.

## Приклад даних і очікування

`data/input.csv` містить три коректні та два некоректні записи.
Усі дані синтетичні.

| Показник | Очікуване значення |
| --- | --- |
| Коректні записи | 3 |
| Середня вартість | 600.00 |
| Загальний виторг | 1800.00 |
| Ургентні візити | 1 |

Рядок 4 пропускається через порожнє ім'я, рядок 5 — через від'ємну ціну.
Програма має повідомити номер рядка й причину та продовжити обробку.
Таблиця — розраховане вручну очікування, а не результат виконання програми.

## Запланований інтерфейс

- `--help`: довідка.
- Звичайний запуск: вхід `data/input.csv`, вихід `output/report.txt`.
- `--input <path>` і `--output <path>`: власні шляхи.
- Для рівня 3: `--version`, що показує версію з POM і номер збірки.

Команди збірки та запуску додамо після створення й перевірки Maven-проєкту.
Працювати з командами потрібно з каталогу `LAB_01/`.
